# Upstream provenance

This Codex edition began from `mgd34msu/goodvibes-plugin` release `v2.3.3` at commit
`e49770e5f37ec9a02f5dc35ed03c2b35bf48929f` on 2026-07-09.

Selected original TypeScript analyzers, tests, templates, and workflow content are carried forward under
the repository's MIT license. Codex-specific manifests, host adapters, state paths, permission
boundaries, session analytics, hooks, and skill metadata are maintained independently here.

The Codex product version starts at `0.1.0`; it is not intended to remain numerically synchronized
with the Claude plugin version.
