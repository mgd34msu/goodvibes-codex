# Third-party notices

GoodVibes bundles or prepares open-source dependencies. Exact versions and
transitive dependency metadata are recorded in the repository root lockfile and
the three `server/*/package-lock.json` files.

Principal runtime components include:

| Component | License |
| --- | --- |
| Model Context Protocol TypeScript SDK | MIT |
| ast-grep NAPI | MIT |
| VS Code ripgrep distribution | MIT |
| web-tree-sitter and grammar WASM modules | MIT |
| undici | MIT |
| sql.js | MIT |
| node-postgres (`pg`) | MIT/ISC transitive mix |
| mysql2 | MIT/Apache-2.0 transitive mix |
| `diff` | BSD-3-Clause |

The runtime lockfiles also include MIT, ISC, BSD, and Apache-2.0 transitive
packages. Their package archives contain the corresponding license texts. This
notice does not replace those licenses.
